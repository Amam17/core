# Setup Guide

Full step-by-step to get GymPilot running.

## 1. Prerequisites

| Tool | Version | Install |
|---|---|---|
| Node.js | 18+ | https://nodejs.org |
| Git | any | https://git-scm.com |
| Vercel CLI | latest | `npm i -g vercel` |

## 2. Clone & Install

```bash
git clone https://github.com/[your-username]/gympilot.git
cd gympilot
npm run install:all
